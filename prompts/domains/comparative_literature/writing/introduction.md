# Introduction Writing — Comparative Literature

Write an introduction for an academic paper in comparative literature.

## Parameters
- Topic: {topic_title}
- Thesis: {thesis}
- Target journal: {journal}
- Language: {language}
- Theoretical framework: {framework}

## Structure
1. Opening hook — a provocative question, quotation, or observation
2. Contextualization — situate the topic within current scholarship
3. Research gap — identify what has been overlooked
4. Thesis statement — state the argument clearly
5. Methodological preview — briefly outline the approach
6. Chapter/section overview — roadmap the paper's structure

## Style Requirements
- Engage with 2-3 key scholarly interlocutors
- Reference at least one primary text in the opening
- Match the target journal's tone and conventions
- Aim for approximately {word_count} words
