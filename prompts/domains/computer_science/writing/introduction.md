# Introduction Writing — Computer Science

Write an introduction for a computer science research paper.

## Parameters
- Topic: {topic_title}
- Hypothesis: {thesis}
- Target venue: {journal}
- Technical approach: {framework}

## Structure
1. Motivating problem — why does this matter?
2. Current limitations — what's wrong with existing approaches?
3. Key insight — what is the core technical idea?
4. Contribution summary — bullet points of contributions
5. Results preview — headline numbers
6. Paper organization

## Style
- Concise, technical prose
- Include a motivating example or figure reference
- Clearly state contributions as a bulleted list
- Aim for approximately {word_count} words
